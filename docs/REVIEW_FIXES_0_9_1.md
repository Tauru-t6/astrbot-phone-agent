# 0.9.1 审查修复与升级说明

本版针对 0.9.0 审查中确认的任务授权、设备绑定、核验和恢复问题修复。该版本没有将审查清单里的 72 条全部视为漏洞，也不声称完成所有工程改进。

## 主要行为

- **任务绑定设备与代次**：计划、写步骤、实时观察和直连路由固定当前绑定；设备身份或直连端点改变，后续步骤停止。在途操作可能已经发生，其结果记为未知，不能当作回滚。
- **授权累计计步**：`max_steps` 是同一 grant 在有效期内的总写步骤预算，跨任务不重置。每次在派发前扣减并落盘，失败、超时和取消不退还；dry-run 只预览预算。人工批准产生的 grant 还绑定该次 run。
- **包级授权**：`open_app`、`close_app`、`suspend_app`、`unsuspend_app` 必须显式列出 packages；空列表不再表示任意应用。`home` 等非包级动作可不传 packages。
- **严格核验**：字符串 `"false"`、`"true"` 和数字 `1` 不当作布尔核验成功。未知前台状态不能证明用户空闲，缺少操作前前台信息不能证明 home/back 成功。
- **故障终态**：损坏的单条历史记录跳过，未知审批状态不可批准；内部核验异常终止 run，执行中步骤记为未知。
- **暂停恢复意图**：新策略在触及设备前保存有限恢复期限。未确认的首次暂停以及取消等待，保留恢复责任。写盘失败时不发新暂停命令；已有永久手动限制的归属不被失败续期删除。
- **明确聊天触发**：回复“批准”“确认”“允许”“同意”“执行”或 ok 才批准；“好”“嗯”“可以”“行”和带问号的疑问不批准。解除要求完整的明确指令，“不要解除限制”等否定或普通提及不触发。
- **群聊读取范围**：提醒列表使用独立的 `phone_reminder_list` 群聊白名单项；Operit 提交及结果使用 `operit_task`、`operit_task_status`。默认不在群聊回显这些私人文本；既有用户身份授权继续生效。
- **后端**：受审批并逐步核验的 task 执行只支持 App。Operit 自然语言工具继续独立工作；不会为了执行一个 task 偷偷切到 ADB。旧 ADB `input_text` 使用设备 shell 引用。

## Relay 升级

插件与 `deploy/relay/relay_server.py` 一起更新。新 Relay 的鉴权 `/health` 返回 `version=0.9.1`、`targeted_tasks=true`。

任务提交新增可选 `target_device_id`。设置后只有带相同 `X-Relay-Device-ID` 的手机能领取；不影响原有无目标任务。App 0.3.26 已发送该设备头，无需为了本版重新安装 App。

受限 task 的 Relay 兜底会检查此能力，旧 Relay 不支持时返回 `relay_targeting_required`，避免把已授权给 A 的命令交给其他设备。

自然语言 Operit 任务缺少跨领取去重。领取租约过期后改为 `unknown`，不再自动入队重做；应检查手机实际状态再手动发起。结构化 App 命令保留同一 command_id 的安全重取，由手机的持久化回执防重复。续租由实际领取设备负责，插件提交方不再伪装领取者续租。

## 兼容与回退

- 旧任务、审批和提醒记录保持可读。没有累计使用账本的旧短期 grant 不迁移，升级后重新授权。
- Phone Companion Context 继续使用 0.3.0；Private Companion 7.1.9 不需要因为本次修复再次升级。
- 没有改变 App 的命令 envelope。新增字段是服务端任务状态和 Relay 提交的可选扩展。
- 回退必须同时考虑新增的授权账本；不要把旧 grant 文件拷回以复活已消耗的权限。升级前备份代码和运行状态。
- 本版没有完成大类拆分、全部同步审计异步化、全部长期内存裁剪和关系角色接口重设计。

## 可复现验证

在完整源码目录运行：

```text
python -m pip install quart pytest
python -m pytest tests -q
node --test tests/test_dashboard.js
```

新增测试覆盖跨 run 和并发额度消耗、重启后账本、持久化失败不派发、损坏历史、未知审批、设备中途换绑、端点变化、旧 Relay 拒绝绑定任务、指定设备领取、自然语言租约过期不重放、取消后的恢复责任、布尔类型、ADB 引用以及聊天和群聊边界。

运行插件 ZIP 按 `.gitattributes` 排除测试以缩小安装包。Release 额外提供完整源码 ZIP（含 tests），审查和复现应使用完整源码或 Git clone。

# 项目优化记录

日期：2026-11-08。范围：AstrBot 插件、可选陪伴桥接、Relay、WebUI 和配套 Android App。

## 结构与本次取舍

项目由两个独立 Git 仓库组成。插件接收聊天/控制台请求并检查权限，任务执行器负责规划、授权和结果核验；`device_app.py` 负责结构化直连/Relay 传输；Android App 通过 Shizuku 执行固定指令。Operit 是单独的自然语言执行后端。健康同步与手机指令不共享执行链路。

现有单测已覆盖较多正常流程，但主要缺口集中于失败后的重复执行、取消后的状态、持久化失败以及界面与真实数据契约不一致。本轮保持现有协议与产品模式，提取有实际复用价值的基础模块，避免在修复过程中同时更换框架或批量升级依赖。

## 已落实的改进

| 方向 | 主要变化 | 对用户的影响 |
| --- | --- | --- |
| 授权和隐私 | 设备命令检查总开关、后端及各功能开关；读屏受群聊隐私规则约束；关怀主动发送检查用户身份 | 本次加强的设备命令、读屏入口遵守开关和访问范围；关怀发送前校验用户资格 |
| 防重复执行 | 任务终态与并发执行保护；Operit 不重放执行结果不明的请求；Android shell 断开后不盲目重放 | Operit/shell 不盲目重放结果未知的请求；App 跨直连/Relay 路径继续复用命令 ID 去重 |
| 取消与核验 | 取消状态持久化；协程中断时将执行中的步骤记为未知；核验必须使用动作发生后的新观测 | 普通取消请求阻止后续步骤，当前步骤仍可能完成；未知结果不再虚报成功 |
| 临时限制恢复 | 续期失败保留旧租约与定时器；提前恢复失败保留后续自动恢复安排 | 网络波动不会悄悄丢失到期恢复责任 |
| 持久化 | Operit 后台任务、提醒和通知使用共享原子写入；通知构建候选批次后再提交 | 磁盘失败保留上一次有效文件，重试不会漏存通知 |
| Relay | 空轮询不再写整份状态；活跃租约校验；已领取任务计入容量；请求体、类型和读取超时校验 | 减少空闲磁盘写入，过期领取者不能继续提交结果 |
| 关怀配额 | 取消退还预留、提交检查 TTL、跨日退款不扣今天额度、成功发送才记录送达 | 配额和最近决策更准确 |
| 控制台交互 | 请求去重、按钮忙碌态、局部错误提示、字段级草稿保护、隐藏页暂停轮询 | 刷新不会覆盖编辑，连点不会重复提交 |
| 控制台新功能 | 创建手机提醒，失败重试复用请求 ID；正确读取每个用户的关怀配额；重启中断的 Operit 任务支持手动重试 | 可直接在网页设置提醒，诊断页显示真实状态，中断任务有明确的恢复入口 |
| Android 交互 | 保存并测试连接；编辑后清除旧测试反馈；审批浮窗使用主线程，显示失败触发兜底 | 避免测试旧配置或显示过期的连接结果 |
| Android 配置保护 | 显式排除云备份与设备迁移中的应用数据；覆盖 DataStore 所在的文件域 | 连接令牌等本地配置不随应用备份或设备迁移复制 |
| 架构 | 共享文件存储与 HTTP 传输基础模块；Android 提取独立 shell 会话和限流逻辑 | 关键逻辑可独立测试，减少重复实现 |

控制台审计所有动态列均进行 HTML 转义；移除了每条私聊都会写入的诊断审计事件。正常动作审计继续保留。

## 性能实测

使用本机 Python、10 万条合成审计记录（26.70 MiB），读取最后 50 条。每种实现连续执行 5 次取耗时中位数，另用 `tracemalloc` 测峰值 Python 分配内存。

| 实现 | 耗时中位数 | 峰值 Python 分配内存 |
| --- | ---: | ---: |
| 原实现：读完整文件后截取末尾 | 114.387 ms | 80.235 MiB |
| 新实现：从文件末尾分块读取 | 0.349 ms | 0.141 MiB |

新实现最多读取 1 MiB，审计接口在工作线程中执行读取。上述数字仅代表这份合成日志、本机缓存条件下的专项测试，不能换算成手机操作或网络链路加速倍数。

## 升级后需要注意

- Operit 结果未知时，先查看手机状态再手动重试。显式 HTTP 错误、超时和中途断连不再自动通过 Relay 重放。
- 携带认证信息的 HTTP 请求不自动跟随重定向；连接配置应直接填写最终地址。
- Relay 提交结果和续租必须对应当前仍有效的领取租约。保持 App/工作流使用领取时相同的设备 ID，并在长任务中按时续租。
- 启用任务私聊确认无需同时开启夜间守护；总开关、用户授权和任务执行开关仍然生效。
- 新增网页提醒属于手机提醒，到期由 App 同步时间线并按通知权限显示；离线时不会承诺准点通知。
- 协程取消无法撤回手机已经接收的操作。现在保留未知状态，避免虚报取消已回滚或动作成功。

本轮未发布 Release、未推送 Git、未改正式连接凭据。Android OEM 后台存活、实际 Shizuku 权限、断网重连、截图回传和手机重启后的行为仍需真实设备验收。
